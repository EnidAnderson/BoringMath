# Candidate PR: cd-structures (`pr/sites-cd-structure`)

## Statement

One new module `BoringMath/CategoryTheory/Sites/CdStructure.lean`:

* `CategoryTheory.CdStructure` — Voevodsky's cd-structure as data: a set
  of distinguished commutative squares `squares : Set (Square C)`.
* `CategoryTheory.CdStructure.IsMayerVietoris` — predicate: every
  distinguished square is a Mayer-Vietoris square for `J`.
* `CategoryTheory.CdStructure.exists_mayerVietorisSquare_and_sheafCondition`
  — every `J`-sheaf of types satisfies Riou's sheaf condition on every
  distinguished square of a Mayer-Vietoris cd-structure. Proved directly.
* `CategoryTheory.GrothendieckTopology.ofCdStructure` — the Grothendieck
  topology generated by a cd-structure (statement-only).
* `CategoryTheory.GrothendieckTopology.sieve_ofTwoArrows_mem_of_mem_squares`
  — the generation clause: the two-arrow sieve of a distinguished square
  covers (statement-only).
* `CategoryTheory.GrothendieckTopology.mem_ofCdStructure_of_forall_mem_squares`
  — the minimality clause (statement-only). Together with the generation
  clause it pins `ofCdStructure` uniquely.
