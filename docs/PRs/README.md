# Candidate pull requests

One note per candidate PR (`pr/<area>-<topic>` branch), named
`<topic>.md`. Each note records:

- the statement(s) being contributed;
- the literature references (with the `REVIEW(citation)` status);
- where the module would live in Mathlib (`Mathlib/<Area>/<Topic>.lean`);
- whether Mathlib already has (part of) it, and how ours differs;
- review notes and the human reviewer's decision.

A note is created when a candidate branch is proposed, and updated through
review. Nothing here is ever actually submitted anywhere.
